# Use a static GitHub Pages site with local progress

The trainer is deployed as a static GitHub Pages site because the learner needs a fast, low-maintenance vocabulary tool without account setup. Progress lives in the browser and can be transferred with a JSON export, which keeps all 414 words, review scheduling, and speech controls client-side. The trade-off is that phones and computers do not sync automatically; adding account-based sync later would require a backend or third-party identity and storage service.
