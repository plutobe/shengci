# 声词

面向学位英语备考的 414 词学习页面，包含发音、主动回忆、三类自测、五阶间隔复习和考试倒计时。

## 本地使用

直接打开 `index.html` 即可。也可以启动本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 部署到 GitHub Pages

把本目录内容放到 GitHub 仓库根目录，在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。页面不依赖构建步骤或服务器环境。

## 学习规则

- 第一次打开页面的日期记为第 1 学习日。
- 默认每天 10 个新词，可改为 5、15 或 20。
- 到期复习先于新词；完成新词和混合自测后才推进到下一组。
- 记忆间隔为 1、3、7、14、30 天。
- 单词和例句使用浏览器自带英语语音，语速与英美音可调。
- 进度保存在当前浏览器，可通过 JSON 文件导出和导入。

## 验证

```bash
node --test tests/*.test.js
```

数据测试会检查 414 条记录、完整字段、唯一单词和十轮计划元数据。
